# neuro-ml-lab
Documenting my journey of learning Computational Neuroscience and Machine Learning

A personal computational laboratory for exploring the intersection of:

- Mathematics
- Machine Learning
- Neuroscience
- Computational Neuroscience

This repository documents my progression from mathematical foundations
to computational neuroscience through implementations, experiments,
simulations, and research-oriented projects.

## Goals

- Build strong mathematical intuition for ML
- Implement mathematical concepts computationally
- Learn machine learning from first principles
- Explore computational models of neural systems
- Work with real neuroscience datasets
- Reproduce and extend research ideas
- Build research-oriented projects

## Current focus

1. Linear Algebra

3. Probability & Statistics
4. Machine Learning
5. Neuroscience
6. Computational Neuroscience

## Philosophy

Learn → Implement → Experiment → Analyze → Document
